## How to fall back
Older versions live in `versions/` (e.g. `versions/index-v1.0-2026-11-21.html`).
To go back: open the older file, copy it over `index.html` in the repo root
(or ask Muse to restore it). GitHub also keeps every commit, so any earlier
version can be restored from the commit history.
